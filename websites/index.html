Website IT questions

What’s the difference between website IT and website design?

Website IT is the technical plumbing: domains, hosting, email, and security. Website design is the look, content, and building of the site itself. We handle the first; Made by Sebby handles the second.

My website is broken. Can you fix it?

Yes, for technical problems like broken plugins, SSL errors, and hosting issues. For design changes, a redesign, or ongoing care, we’ll point you to Made by Sebby.

Do you offer ongoing website maintenance?

Ongoing website care (updates, backups, content changes, SEO) is handled by Made by Sebby’s Website Care plans. We still take one-time technical fixes anytime.
